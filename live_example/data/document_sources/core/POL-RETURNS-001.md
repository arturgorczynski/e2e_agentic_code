# Commercial return window

This fictional Acme policy defines an ordinary commercial return request window of
**{{WINDOW_DAYS}} calendar days** after recorded delivery. It is a teaching business
rule, not a statement of consumer law or a recommendation about a real customer's rights.
An eligible request is still subject to inspection and authorization.

## Choose the applicable version

Use the version effective on the event date being discussed. The current document
must not be applied retroactively to an older event. When comparing an earlier date
with today, cite both version IDs and effective ranges. In business questions, today
means the fixed Acme reference date, not the computer's wall-clock date.

If delivery evidence is missing, do not invent a delivery date to calculate eligibility.
If the request concerns damaged goods, use the complaint procedure and preserve the
ticket's evidence. A return request, a credit note and a cash refund are separate events.
No source cancellation is sufficient evidence that a physical return happened.

## Handoff

Support records the affected order, product, quantity, event date and reason. Warehouse
inspection determines whether goods were received and their condition. Finance separately
authorizes any credit. The learning assistant can explain the applicable window and
draft a next-step report; it cannot approve returns, promise compensation or adjust stock.
Historical versions stay readable for authorized context-selection exercises and are
clearly marked superseded rather than deleted.
